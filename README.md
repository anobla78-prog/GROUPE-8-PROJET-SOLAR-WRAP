## Mode d'emploi
1. Déposer chaque nouvelle information dans l'espace correspondant.
2. Pour toute tâche, préciser un responsable, une échéance et un statut.
3. Consigner les décisions importantes avec leur date et leur justification.
4. Mettre à jour le tableau de bord en fin de journée.
5. Ne pas publier de données personnelles ou confidentielles : ce dépôt est public.
